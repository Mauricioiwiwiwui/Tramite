# NOVA MAYOREO

Sistema web para crear notas de remisión con catálogo de productos y generar/guardar como PDF mediante la impresión del navegador.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda y abre la URL que GitHub Pages te proporcione.

No requiere servidor, base de datos ni instalación. Funciona como sitio estático.
