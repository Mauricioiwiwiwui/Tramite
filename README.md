# Santana Management — versión 1

Panel web mobile-first para trámites, consultas, herramientas y accesos a aplicaciones.

## Publicar en GitHub Pages

1. Sube **todo el contenido de esta carpeta** a un repositorio.
2. En GitHub abre **Settings → Pages**.
3. Selecciona la rama que contiene `index.html` y la carpeta raíz `/ (root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.

## Importante

- No se incluyen precios en los servicios ni en las promociones.
- El panel muestra `+999` como saldo disponible de referencia.
- El portapapeles es temporal y vive únicamente mientras la pestaña está abierta.
- Las notas usan `sessionStorage` y se eliminan al terminar la sesión del navegador.
- Favoritos, recientes y estadísticas son locales al navegador.
- Los accesos a portales externos no permiten saber si el usuario descargó algo dentro del sitio externo.
- Santana AI en esta versión es un asistente local para localizar las herramientas del catálogo. No expone ninguna API key.
- El centro de música permite seleccionar archivos de audio locales desde el dispositivo; los archivos no se suben al servidor.
- Las funciones PDF se ejecutan en el navegador con PDF-LIB/PDF.js cargados desde CDN.

## Funciones incluidas

- Inicio con buscador inteligente, accesos rápidos, promociones compactas, favoritos y recientes.
- Trámites y consultas con enlaces web y accesos a WhatsApp.
- Aplicaciones: CFE Contigo, IMSS Digital y WhatsApp.
- Herramientas: calculadora, porcentajes, fechas, PDF, comprobantes, tickets, gastos, contraseñas, notas, portapapeles temporal y folios.
- Centro de música.
- Santana AI local.
- Panel de actividad/estadísticas.
- Diseño responsive para móvil y escritorio.
- Módulos rescatados del proyecto anterior: Actas Certificadas y No Deudor Alimentario.
