SANTANA HUB — GITHUB PAGES

Sube SOLAMENTE index.html a tu repositorio de GitHub Pages.
No necesita servidor, base de datos, claves ni instalación.

Incluye:
- Portapapeles
- Generador seguro de contraseñas/códigos
- Notas persistentes
- Visor/lista local de archivos
- Calculadora
- Texto privado
- Compartir página
- Diseño móvil

IMPORTANTE: el módulo Archivos es local al dispositivo. GitHub Pages no permite que visitantes suban archivos a un almacenamiento compartido sin backend.
